# 🛠️ SQL Scripts & Data Validation

This directory contains the core technical assets for the 2015 Hotel Booking Analysis project. It is organized into two primary sub-folders to separate the logic (code) from the evidence (results).

---

## 📁 Folder Structure

### 1. `sql_codes/`
Contains 6 structured SQL scripts developed in Google BigQuery. These queries handle the data lifecycle from initial cleaning to advanced insights.
* **01 to 03:** Focus on data preparation and establishing a `DISTINCT` dataset to match spreadsheet cleaning.
* **04:** Analyzes Seasonal ADR (Average Daily Rate).
* **05:** Breaks down Meal Preference distribution.
* **06:** Investigates Lead Time vs. Cancellation rates.

### 2. `sql_results/`
Contains the exported CSV files generated by the BigQuery scripts.
* `04_Seasonal_ADR_Results.csv`: Proves the **$150.81** ADR validation.
* `05_Meal_Type_Results.csv`: Statistical breakdown of guest dining choices.
* `06_Lead_Time_Results.csv`: Categorical analysis of booking behavior.

---

## ⚙️ Technical Strategy: "The Dual-Validation"
The scripts here were written specifically to validate findings previously discovered in Google Sheets. 

**Key Logic Applied:**
* **CTE usage:** Used `WITH` clauses to ensure all calculations were performed on a pre-cleaned "Unique" version of the hotel data.
* **Filter Consistency:** Applied `is_canceled = 0` and `adr > 0` across all scripts to ensure we only analyzed successful, revenue-generating bookings.
* **Rounding Logic:** Adjusted for BigQuery's precision to explain the $0.07 variance found during the audit.

---

## 🚀 How to Use
These scripts are ready to be imported into any Google BigQuery project using the standard Hotel Booking dataset. Results can be verified by comparing the CSVs in `sql_results/` to the dashboard visualizations.
